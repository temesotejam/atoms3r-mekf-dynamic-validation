# V46ai / 0.46.34 — 次ピーク予測を角速度式に統一

> 過去の版の記録です。現在は[V46ajで遅延補償を3 ms固定](V46AJ_FIXED_3MS.md)にしています。

V46ahにあったP1への切り替えを削除しました。最初の通常ZEROクロス判断から、
次ピークの基準値を、そのZEROクロスの角速度と進行方向だけで計算します。

```text
A_rate_plus  = 7.217460941 + 0.286814471 * (abs_rate_dps - 65)
A_rate_minus = 8.399746959 + 0.130807354 * (abs_rate_dps - 65)
A_baseline   = max(0, A_rate)
A_next      = A_baseline + g_side * Q
```

以前から使っている係数は変更していません。25%の混合やP1との差の上限はありません。
低速時に直線式が負になる場合だけ、振幅を0°とします。ゼロ下限は連続であり、P1へ戻しません。
非有限値・不正な方向は既存の無出力処理へ渡します。

## 削除した処理

- 直前ピークからP1の減衰を計算する関数、呼び出し、減衰係数。
- 最初の10秒をP1にする条件。
- 目標8°・遅延補償3 msだけに限定する条件。
- 直前ピーク振幅と角速度による状態範囲の条件。
- P1へ戻す処理と、P1との差を求める計算。

予測関数の引数は `abs_rate_dps` と `side` の2つです。
全目標（8°・10°・12°）と全遅延設定（0・3・6・9 ms）でこの方式を使います。
遅延設定はZEROクロス検出の先読み時間にだけ作用し、予測方式の切り替えには使いません。

## 維持した処理

MEKF姿勢・バイアス推定、3 msの既定遅延補償、隣接サンプルの角速度補間、ピーク検出、
物理半周期の順序、正負の誤差積分（Ki=0.10）、Qゲイン（正0.29032・負0.25455）、
電流モデル、パルス幅探索、300 mA・最大100 ms、起動パルス、非常停止、IMU取得、LED同期。

測定ピークは記録と目標誤差のフィードバックに使いますが、自由次ピーク予測の入力には使いません。
角度とエネルギーを変換する形状由来のポテンシャル関数も残します。
これは直前ピークから次ピークを予測するP1減衰モデルとは別用途です。
形状式の定義域や非有限値に対する既存の出力停止条件は継続します。

## 記録

RWLOG v51の時系列配置と既存CSV列を維持します。

- `attitude_validation_revision`: `v46ai_rate_only_baseline_20260919`
- `rate_baseline_revision`: `v46ai_rate_only_all_zero_crosses_20260919`
- `rate_baseline_previous_peak_used`: `false`
- `rate_baseline_p1_fallback_enabled`: `false`
- `p1_free_peak_before_rate_deg`、`rate_baseline_correction_deg`: `null`（計算しない旧列）
- `rate_baseline_peak_deg`: ゼロ下限前の角速度式の値。
- `free_next_peak_amplitude_deg`: 実際に使った非負の基準値。
- `rate_baseline_reason`: 0=通常適用、5=角速度式を0°下限で適用、4=不正入力、255=未評価。
- 過去の1〜3（開始10秒・他設定・状態範囲外）は新しい通常判断では発生しません。

## 検証

本番ヘルパーの32,023ケースで、正負0〜160°/s、旧境界の直前・直後、ゼロ下限、
不正入力、9158の70.0565°/sの事例を検証しました。従来の15自動テストも通過しています。
旧ハッシュは書き換えず、明示した変更だけを逆変換して、残す処理が変わっていないことを検査します。
新版の本番関数と結線のテストは、この逆変換を使わず直接実行します。

6 Run（d170、8cde、ead9、4e80、2802、9158）の記録状態415判断で再計算し、
高速探索と全候補探索が全件一致しました。目標8°・10°・12°への置換も1,245件一致しました。
P1への切り替えは0、ゼロ下限は6件、最大探索評価数44回、記録状態に対する幅変更225件です。
元の実機幅とPC計算には既知の1 ms差が2件あり、完全な実機再現とは扱いません。

再計算スクリプトは `tools/replay_v46ai_rate_only.py` です。
記録した電流モデルとKi状態を固定した一判断ごとの検査であり、変更後の閉ループ運転の模擬ではありません。
V46ah再計算ツールは凍結した旧ヘルパーを明示して使い、過去の評価を再現できます。

状態範囲を外したときの予測精度が全領域で良いと確認されたわけではありません。
今回の目的は、ユーザー指定どおり予測を角速度式一本にし、式の切り替えによる段差をなくすことです。
新しいパルス列での振幅と予測誤差は実機測定で確認します。
