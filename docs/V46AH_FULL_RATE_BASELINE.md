# V46ah / 0.46.33 — 角速度による次ピーク予測を100%採用

V46agの25%補正と、従来P1との差を最大±0.5°に制限する処理を外します。
既存の適用条件を満たす場合、角速度式の出力を次ピーク予測の基準値へ直接代入します。

```text
A_rate_plus  = 7.217460941 + 0.286814471 * (abs_rate_dps - 65)
A_rate_minus = 8.399746959 + 0.130807354 * (abs_rate_dps - 65)
A_baseline   = A_rate
logged_delta = A_rate - A_P1
A_next      = A_baseline + g_side * Q
```

適用範囲の条件はV46agと同じです。

- 目標8°、遅延補償3 ms、測定開始から10秒以上。
- 次が正側：直前ピーク8.3〜9.8°、角速度61.5〜72°/s。
- 次が負側：直前ピーク6.7〜9.0°、角速度59〜70°/s。
- 最初の10秒、他の設定、状態範囲外では従来P1を使います。

範囲内では角速度式の基準値が正になります。P1への補正量の上限はありません。
P1自体も従来通り計算し、範囲外で使う値と比較用ログを維持します。

## 維持する処理

MEKF姿勢推定とバイアス推定、開始姿勢基準のピーク振幅、次側ピーク待ち、戻り3サンプル確認、
3 msの角度先読み、角速度の補間、Qゲイン（正0.29032・負0.25455）、Ki=0.10、
パルス幅の探索、300 mA・最大100 ms、起動パルス、非常停止、IMU取得、LED同期は維持します。
重みのオンライン学習や、新しいKF・行列計算は追加しません。
変更した補正関数は、適用範囲内で角速度式を直接代入し、ログ用の差を計算するだけです。
選ぶパルス幅が変わるため、実機の処理時間は次のログで確認します。

## 既存データでの根拠

式の係数はd170と8cdeで決定したものを固定しています。
後から取得したead9・4e80について、記録された状態とQを固定して一段先を再計算しました。
比較区間は次ピークが10〜30秒、各46件です。既存の適用条件は維持しています。

| 次ピーク予測のRMSE | ead9 | 4e80 |
|---|---:|---:|
| 従来P1＋記録Q | 1.269° | 1.211° |
| V46agの25%補正 | 0.995° | 0.920° |
| 100%・補正上限±0.5° | 0.867° | 0.801° |
| V46ah：100%・補正上限なし | 0.378° | 0.269° |

これはMEKFの次ピークに対する予測誤差です。目標8°への実機制御誤差ではありません。
ead9の2件は状態範囲外でP1を使うため、範囲制限も外した角速度式だけの評価値0.297°とは異なります。
100%・補正上限なしで運転した実機の安定性や振幅精度は、これから確認します。

## 記録と検証

RWLOG v51の時系列配置と既存イベント列は維持します。

- `rate_baseline_revision`: `v46ah_rate_baseline_100pct_no_cap_20260919`
- `rate_baseline_blend`: `1.0`
- `rate_baseline_delta_cap_enabled`: `false`
- `rate_baseline_delta_cap_deg`: `null`
- 適用時は `free_next_peak_amplitude_deg == rate_baseline_peak_deg`。
- `rate_baseline_correction_deg` はP1との差全量を記録し、±0.5°を超えることがあります。
- 旧ジャイロ座標用の `correction_deg` は別の補正で、無効のままです。

本番の補正関数を使う6518ケースで、正負の直接代入、±0.5°を超える変更、状態範囲の端点と直外、
開始10秒・8°・3 ms条件、範囲外P1、非有限値、CSVの後方互換性を確認しました。
従来のハッシュ基準は維持し、版名の変更だけを追加の明示的な変換で扱います。

`tools/replay_v46ah_full_rate.py` はデコードしたmetadataを受け取り、記録した電流モデル・Kiを固定して、
本番の補正関数と既存のfloat32パルス幅探索を再実行します。高速探索と全候補探索も比較します。
4 Runの277判断は全件で両探索が一致しました。補正適用184件、見送り93件、パルス幅の変更121件、
探索の最大評価数は44回でした。適用時の再計算幅は正側最大62 ms、負側最大15 msです。
これは実機の将来推移を模擬した結果ではなく、変更後の実機パルス幅の保証ではありません。
元の実機幅のPC再計算には277件中2件で1 msの差があり、完全再現とは扱いません。
8cde event 70は実機17 ms・PC16 msで、既知の同点・丸め境界です。
4e80 event 24は実機0 ms・PC1 msで、実機が記録した目標エネルギーを使うとPCも0 msになります。
後者は補正開始前の判断です。これらの差は再計算の診断に残し、新版が旧版と完全一致するとは扱いません。
