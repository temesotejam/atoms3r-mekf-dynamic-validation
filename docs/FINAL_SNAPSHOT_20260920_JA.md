## 2. 現在の角度推定

現在のAutonomousでは、AtomS3R内蔵BMI270のジャイロと加速度を6状態MEKFで統合して姿勢を推定します。

- MEKFの連続姿勢から、計測開始姿勢を0°とした角度を作る。
- ピーク振幅の測定には、3 ms先読みを加えていないMEKF角度を使う。
- ZEROクロス判定だけは、バイアス補正済み角速度を用いてMEKF角度を3 ms先へ進める。
- 3 ms先読みは短時間一定角速度を仮定した軽量な時間補償であり、別のクォータニオン先読みを重ねない。
- Madgwick、ジャイロ単独積分角、加速度単独角は比較・診断用であり、現在のAutonomous姿勢判定には採用しない。

詳細は [ATTITUDE_ESTIMATION_V46AI_JA.md](ATTITUDE_ESTIMATION_V46AI_JA.md) を参照してください。

## 3. 次ピーク予測

V46ai以降、通常ZEROクロスからの次ピーク基準振幅は角速度式へ統一しています。
直前ピーク振幅を予測式の入力には使いません。

```text
A_rate_plus  = 7.217460941 + 0.286814471 * (abs_rate_dps - 65)
A_rate_minus = 8.399746959 + 0.130807354 * (abs_rate_dps - 65)
A_baseline   = max(0, A_rate)
A_next       = A_baseline + g_side * Q
```

低速側で直線式が負になる場合だけ0°を下限とします。
具体的な係数と履歴は [V46AI_RATE_ONLY_BASELINE.md](V46AI_RATE_ONLY_BASELINE.md) を参照してください。

## 4. 実機で確認できていること

2026-09-19の測定 `20260919_190539_375_3943.zip` は、
V46ai、目標8°、遅延補償3 ms、30秒の条件で実施したものです。

- 動画とファームウェアのピーク: **69個すべて一対一で対応**
- 10〜30秒の46ピークにおけるMEKFと動画のピーク差: **RMSE 約0.103°**
- 同じ区間の目標8°に対するMEKFピークのRMSE: **約0.643°**
- IMU取得・配信: ジャイロ/加速度とも12,142件、配信欠落・キュー落ち0
- ジャイロ取得間隔: 平均約2.471 ms、最大約3.905 ms

ここで重要なのは、**姿勢推定の誤差と、8°へ振幅を揃える制御誤差は別の問題**という点です。
この測定では、MEKFは実際の揺れのピークを動画に対して良く追えている一方、
目標8°への追従にはそれより大きい誤差が残っています。

したがって、このリポジトリで確定した到達点は、
**現在の角度推定を以後の制御検討の土台として扱える状態まで整理・検証したこと**です。

## 5. 3 ms固定化について確認できている範囲

実機測定3943はV46aiで3 msを選択した条件です。
V46ajは、その測定で使った3 msの演算を残し、0 / 6 / 9 msの選択機能と関連UI/APIを削除した版です。

したがって、

- 3 msを使うZEROクロス補償の考え方と実測結果はV46ai測定で確認済み。
- V46ajの固定3 ms処理、開始API、メタデータ、UIはホストテストとESP32-S3ビルドで確認済み。
- V46ajへ固定化した後だけを対象にした新しい実機比較測定は、この保存時点では追加していない。

3 msが物理的な真の遅延を厳密に表す、あるいは全条件で最適である、という意味にはしません。
現在の運用値として3 msに固定した状態を保存します。

詳細は [V46AJ_FIXED_3MS.md](V46AJ_FIXED_3MS.md) を参照してください。
